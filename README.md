# Birthday Website

A romantic multi-page birthday website for your girlfriend.

## Pages
- `index.html` - landing page
- `gallery.html` - photo gallery page
- `letter.html` - love letter page
- `story.html` - our story timeline page
- `style.css` - styling and theme
- `script.js` - simple reveal animations

## How to run
Open `index.html` in a browser, or deploy it with GitHub Pages, Vercel, or Netlify.

## Notes
The current version uses romantic placeholder images for a polished look. If you want, replace them with your real photos in the `img` source URLs to personalize it further.
